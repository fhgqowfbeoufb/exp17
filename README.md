AIM

To study and apply fundamental data visualization techniques in Python using Matplotlib and Seaborn for effectively illustrating trends, comparisons, distributions, and relationships within data.

THEORY

Data visualization is the process of representing data in a graphical format to better understand patterns, trends, and relationships. It plays a crucial role in simplifying complex data and making it more interpretable. Python libraries such as Matplotlib and Seaborn offer a wide range of tools to create visualizations including line graphs, bar charts, histograms, and scatter plots.

These graphical representations help in analyzing changes over time, comparing different categories, understanding how data is distributed, and identifying correlations between variables. Seaborn builds upon Matplotlib by providing enhanced visual appeal and more convenient functions for creating statistical plots, making it especially useful for data analysis.

FUNCTIONS (ONE-LINE EXPLANATIONS)
plot() – Generates a line graph to visualize trends in data
figure() – Defines the size and layout of the plotting area
xlabel() – Assigns a label to the x-axis
ylabel() – Assigns a label to the y-axis
title() – Adds a descriptive title to the plot
legend() – Displays labels for multiple data series on the graph
bar() – Creates a bar chart to compare different values
text() – Inserts text or value labels within the plot
grid() – Adds grid lines for better readability
xticks() – Customizes the labels or positions on the x-axis
hist() – Plots a histogram to represent data distribution
axvline() – Draws a vertical reference line (e.g., mean or threshold)
scatter() – Produces a scatter plot to show relationships between variables
show() – Displays the final plot on the screen
lineplot() – Creates a line chart using Seaborn
barplot() – Creates a bar chart using Seaborn
histplot() – Generates a histogram using Seaborn
scatterplot() – Produces a scatter plot using Seaborn
CONCLUSION

In this study, basic data visualization techniques were successfully implemented using Matplotlib and Seaborn. Various types of plots were created to represent trends, comparisons, distributions, and relationships within datasets. These visualization methods are essential for simplifying data interpretation and supporting effective decision-making in data analysis.
